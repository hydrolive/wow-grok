# Changelog

## 0.1.0

- In-game WowGrok window (`/wow-grok`, `/grok`, `/ai`, `/r`) with chats, context, shift-click tooltips, Connect, and Allow & retry.
- Companion with echo, Grok CLI, and optional xAI API backends. No ACP in this version.
- Pixel strip out, 200 load-on-demand slots in, signal wavs, and a `/reload` fallback.
- `npm test` covers the protocol, slots, echo companion, capture decoder, and a scripted addon session without WoW or a Grok login.
